# Cairn

Releases of **Cairn**, a study app for the ISACA CISA and AAISM exams, and the
current set of reviewed questions it downloads.

- Mac app: download the `.dmg` from the [latest release](https://github.com/4realIA/cairn-releases/releases/latest).
- Windows: Cairn is available from the Microsoft Store.
- [Privacy policy](PRIVACY.md)
- Questions or problems: [open an issue](https://github.com/4realIA/cairn-releases/issues).

Cairn is an independent study tool, not affiliated with or endorsed by ISACA.
